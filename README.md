# Read-And-Write-CSV-Files-in-Python
This is to practice read and write csv files in python. It is an order tracking system. I will implement SQL later

#CSV File Info
Enter CSV file content must be in the following format for program to run:
For Customer:
customer_id (int), name (str), address (str)
For Product:
product_id (int), name (str), price (float), quantity in stock (int)
For Employee:
employee_id (int), name (str), position (str), years of experience (float)
The orders will be written to a CSV file in the following format:
order_id (int), customer_id (int), employee_id (int), product_id (int), quantity (int), price (float), value (float)

This program will only create/update/add objects not delete them. If you want to delete an object, you will have to do it manually in the CSV file.
